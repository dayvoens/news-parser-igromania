# Telegram Game News Bot & Parser

Асинхронный Telegram-бот и независимый RSS-парсер игровых новостей. Проект построен на раздельной архитектуре с использованием базы данных SQLite в качестве общей точки связи.

## 🛠 Технологии
* **Python 3.x**
* **aiogram 3.x** (для Telegram-бота)
* **requests** & **xml.etree.ElementTree** (для парсинга RSS-ленты)
* **SQLite3** (для хранения новостей)

## 📐 Архитектура проекта
Проект разделен на два независимых модуля:
1. `gamesnews.py` — скрипт-парсер, который запускается по расписанию, забирает свежие новости из RSS-ленты Игромании, записывает их в БД и завершает работу.
2. `bot.py` — Telegram-бот, который запущен постоянно. При нажатии пользователем кнопки он мгновенно забирает кэшированные новости из базы данных.

Такой подход защищает бота от падений, если сайт с новостями изменит структуру или заблокирует запросы.

## 🚀 Как запустить локально

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/dayvoens/news-parser-igromania.git
   cd news-parser-igromania
   ```

2. Зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Создайте файл .env в корне проекта и добавьте туда токен вашего бота:
   ```
   BOT_TOKEN=ваш_токен_из_BotFather
   ```

4. Запустите парсер для первоначального наполнения базы данных:
   ```bash
   python gamesnews.py
   ```

5. Запустите Telegram-бота:
   ```bash
   python bot.py
   ```
